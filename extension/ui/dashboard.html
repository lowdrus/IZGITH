EULA

O IZGITH é uma ferramenta local de apoio à automação, auditoria, exportação e organização. O usuário mantém controle sobre arquivos, contas e destinos. O IZGITH não coleta credenciais nem executa comandos externos silenciosamente.

Guia Rápido

CONV-D: “Ativar/Desativar” liga ou desliga o módulo. Em uma conversa, “Baixar Conversa” permite Tudo ou Ultima Rodada e depois o formato. O navegador abre o diálogo para você escolher o local de salvamento.

UPPER URL: cole a URL de uma conversa suportada e, opcionalmente, um repositório GitHub como referência de destino. O módulo abre a conversa; a exportação é feita pelo CONV-D. Nenhuma credencial é solicitada pelo UPPER URL.

Download por Link: use uma URL HTTP/HTTPS direta de arquivo. O navegador gerencia o download; FTP, SMTP, POP e torrents não são transportes genéricos de download pela API do navegador.

SONPEF: selecione arquivos .ps1/.py. O IZGITH lê os arquivos no navegador e cria um artefato unificado local, sem executar o código selecionado.

Fila Rápida: é uma fila local para manter itens preparados e acompanhá-los antes do processamento. Ela serve para organizar pacotes/tarefas sem executar comandos externos automaticamente.

Selecionar .ZIP/.CRX: escolha um pacote local para conferir nome, tamanho e extensão antes de inspeção, auditoria ou instalação. Use quando receber uma extensão/pacote e quiser verificar o arquivo antes de prosseguir.

Assistentes: IZART, Ayella e Júlia têm focos diferentes e conversam dentro do painel inicial. Use Limpar chat para reiniciar a conversa.

Janela: “—” minimiza a janela do IZGITH sem fechar o navegador; “×” fecha somente a janela do IZGITH.

Configurações

Como funcionam os modos

Ultra + Controlado — Unificado: automatiza tarefas internas do navegador e mantém ações sensíveis sob controle.

Controlado: privilegia previsibilidade e confirmações antes de ações relevantes.

Ultra: reduz interrupções e prioriza velocidade para tarefas locais suportadas.

Como funciona o modo automático

Auto preparar: prepara antecipadamente dados, arquivos, parâmetros e sequência, mas não envia nem executa uma etapa externa automaticamente.

Auto com confirmação: prepara a ação e mostra exatamente o que será efetivado; a execução depende da confirmação do usuário.

Manual: cada ação é iniciada pelo usuário, sem preparação automática.

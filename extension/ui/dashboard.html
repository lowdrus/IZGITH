Guia Rápido

Identidade & Host: o IZGITH abre sem Native Messaging; “Testar host” é opcional. O navegador não permite que uma extensão registre silenciosamente um host nativo por conta própria; isso precisa de um instalador/componente externo autorizado.

Ferramentas: CONVGPT, SONPEF, KIT_UNICO, CHAT_HISTORY e IZART aparecem no Centro de Ferramentas. Configurações: Unificado, Controlado ou Ultra. Logs: acompanhe operações. Temas: 36 presets e profundidade 2D/3D/4D.

Janela: use “—” para minimizar e “×” para fechar o dashboard.

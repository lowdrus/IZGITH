Guia Rápido

CONVGPT: abra a conversa no ChatGPT e clique no botão Baixar conversa · CONVGPT dentro da página, ou use “Exportar conversa atual” no Dashboard. Não abre uma nova conversa.

SONPEF: clique “Selecionar scripts”, escolha os .ps1/.py e o IZGITH faz a unificação no navegador e baixa o resultado. Não usa PowerShell nem host nativo.

IZART: clique “Conversar” e envie mensagens no painel. Ayella é o nome canônico.

Host: não é requerido pelo baseline autônomo. O erro “Specified native messaging host not found/forbidden” deixa de ser caminho operacional porque a extensão não solicita mais Native Messaging.

Janela: “—” minimiza e “×” fecha.

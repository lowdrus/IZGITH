# Fontes históricas

Esta área preserva código útil dos projetos que antes estavam misturados na raiz. Ela serve apenas como referência para evolução do IZGITH e fica fora do build, dos pacotes, dos testes e da análise CodeQL.

Arquivos compactados duplicados, executáveis, pacotes inválidos e exportações pessoais foram removidos. As licenças originais permanecem junto das fontes quando disponíveis.

# Segurança

Não publique tokens, chaves privadas, perfis do navegador nem exportações de conversas neste repositório. Credenciais expostas devem ser revogadas imediatamente no provedor.

O IZGITH não executa um pacote durante a preparação. A extração bloqueia travessia de diretórios e links simbólicos. O laboratório abre a extensão em perfil temporário separado, mas isso não transforma código desconhecido em código confiável.

Para relatar uma vulnerabilidade, use **Security → Report a vulnerability** no GitHub. Não abra uma issue pública contendo credenciais ou dados pessoais.

# IZGITH — Nomenclatura oficial das assistentes

## Regra canônica

Os nomes oficiais das assistentes internas do IZGITH são:

- **Júlia**
- **Ayella**
- **IZART**

### Ayella

O nome oficial é **Ayella**.

Não utilizar, na interface, documentação, registros ou mensagens:

- Ayelle
- alias Ayella
- Alias: Ayella
- Ayella como apelido

**Ayella não é alias. Ayella é a identidade/nome oficial da assistente.**

## Regra de manutenção

Qualquer novo componente que registre ou apresente as assistentes deve consumir esta nomenclatura canônica e não criar aliases visuais para os nomes oficiais.

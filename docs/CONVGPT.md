# CONVGPT

Abra uma conversa em `chatgpt.com/c/`, `chatgpt.com/g/` ou `chatgpt.com/gg/` e clique em **Baixar conversa · CONVGPT**. O IZGITH gera localmente dois arquivos: Markdown legível e JSON estruturado.

O exportador lê somente as mensagens carregadas na página selecionada. Conversas muito longas podem exigir rolar até o início para que o ChatGPT carregue todo o histórico. Nenhum conteúdo é enviado a servidores do IZGITH.

# Privacidade

O IZGITH armazena preferências, fila e histórico somente no armazenamento local da extensão. O monitor do GitHub consulta apenas a API pública de releases do repositório informado.

O host local recebe comandos somente da extensão autorizada no manifesto Native Messaging. Caminhos e resultados permanecem na máquina. O IZGITH não envia arquivos de extensões, conversas, tokens ou dados pessoais para um servidor próprio.

Antes de compartilhar logs, remova nomes de usuário, caminhos pessoais e credenciais.
